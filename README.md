# Whisperwood: The Windows Story Trail

Explore a hand-drawn woodland island on a scavenger hunt through Windows
history and selected Windows 11 features. Find one field note at a time, read
its lesson, and answer the check-in to open the next gate. Future clues stay
hidden until you learn the note in front of you.

## Play

Run `python test.py` to open the game in a new browser window, or open
`game.html` directly in a modern browser.

- Use `W`, `A`, `S`, `D` or the arrow keys to explore.
- Press `E` or click **Examine** when you find a glowing field note.
- Read the note, then answer its question to unlock the next trail gate.
- Mori the moth can offer a reminder if you need a hint.
- Use `+` and `-` or the map buttons to zoom. Click the fullscreen button or
  press `F` to maximize the game.
- On smaller screens, use the on-screen arrow buttons.

The trail has five short Windows history lessons followed by nine selected
Windows 11 features. Some features require compatible hardware or a supported
Windows update. The game uses local HTML, CSS, JavaScript, a painted woodland
texture, and high-DPI canvas rendering; it does not need additional packages.
