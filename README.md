# Windows 11 Perk Quest

A small, interactive Python quiz game that takes you through standout features
introduced or notably enhanced in Windows 11 compared with Windows 10. Learn
what each perk does, where to try it, and answer a question at every stop.

## Play

Run the game with Python 3:

```text
python test.py
```

Enter `1`, `2`, `3`, or `4` to answer each question. Enter `Q` to end the tour
early. Features such as Auto HDR, Dynamic Lighting, and Windows Studio Effects
may require a compatible display, accessory, or PC.
