# Whisperwood: Windows Volcano Scroll Hunt

Explore a hand-painted island wrapped around a large volcano. Find five
Windows history scrolls and nine selected Windows 11 feature scrolls. Only
the current scroll appears; the journal compass gives a broad direction, not
its exact location. The final scroll waits on the summit.

Read each scroll and answer its check-in before the next appears. Scrolls can
be read from a few steps away, and the volcanic slope stays too steep until
the final climb.

## Play

Run `python test.py` to open the game in a new browser window, or open
`game.html` directly in a modern browser.

- Use `W`, `A`, `S`, `D` or the arrow keys to explore around the volcano.
- Press `E` or click **Read scroll** when you're close to the active scroll.
- Check the journal's compass for its general direction; explore to find it.
- Mori the moth can repeat the current bearing.
- Use `+` and `-` or the map buttons to zoom. Click the fullscreen button or
  press `F` to maximize the game.
- On smaller screens, use the on-screen arrow buttons.

Some Windows 11 features require compatible hardware or a supported update.
The game uses local HTML, CSS, JavaScript, painted woodland art, and high-DPI
canvas rendering; it does not need additional packages.
